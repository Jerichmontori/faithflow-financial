# Church Finance Hub

uatkan aplikasi " BUMOTIK FINANCIAL" yang sistem manajemen keuangan dan administrasi gereja dengan tampilan profesional, modern, responsive, dan mudah digunakan. Aplikasi digunakan untuk mengelola seluruh transaksi keuangan gereja, administrasi, approval pengeluaran, monitoring keuangan secara realtime, pengelolaan mata anggaran, jadwal ibadah seluruh UPK, jadwal pelayanan pendeta, serta laporan harian, mingguan, bulanan dan tahunan. ROLE USER

Super Administrator

Ketua BPMJ

Admin Keuangan

Sekretaris

Pendeta

Auditor

Viewer

Setiap role memiliki akser berbeda DASHBOARD

====================================================

Dashboard menampilkan secara realtime:

• Saldo Kas

• Kas Masuk Hari Ini

• Kas Keluar Hari Ini

• Total Kas Bulan Ini

• Anggaran vs Realisasi

• Grafik Pendapatan

• Grafik Pengeluaran MATA ANGGARAN

====================================================

Setiap transaksi WAJIB memilih kode mata anggaran. Dashboard harus menampilkan persentase penggunaan anggaran.
